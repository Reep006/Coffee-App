# Coffee Voting App ☕
A full-stack voting application built using Flask and MongoDB.

## Features
- Coffee voting system
- MongoDB database integration
- Real-time vote updates
- Responsive UI
- Flask backend APIs

## Technologies Used
- HTML
- CSS
- JavaScript
- Python Flask
- MongoDB Compass
